## Current Project

### AI-Powered SAP Integration Incident Manager

Building an SAP Integration Suite solution that:

- Captures failed integration messages
- Creates a canonical incident format
- Uses AI to classify root causes
- Routes incidents to the correct support team
- Handles controlled retries through JMS
- Supports human approval for sensitive actions
- Maintains correlation IDs and audit information

The project will initially use a mock AI classifier and later integrate with SAP AI Core and Generative AI Hub.
